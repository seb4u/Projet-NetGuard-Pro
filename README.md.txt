# Projet NetGuard Pro

## Description
NetGuard Pro est un IDS éducatif permettant de détecter des attaques réseau.

## Fonctionnalités
- Détection Port Scan (TCP SYN)
- Détection SYN Flood
- Agent de sniffing réseau (Scapy)
- Serveur FastAPI
- Dashboard de visualisation

## Architecture
- agent/
- server/
- dashboard/
- simulateur/
